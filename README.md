Official Homebrew repository for **Anubis Agent — The Guardian of Code** (AI Agent & Local LLM Sovereign Engine).

## Install on macOS & Linux

```bash
brew tap Groennesby/anubis

```

Once installed, type `anubis` in your terminal!
